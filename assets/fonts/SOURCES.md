# Sumber font

Tipografi diperiksa langsung pada [situs resmi AIM](https://aimindonesia.co.id/) tanggal 5 November 2026 melalui gaya teks yang diterapkan pada browser.

| Pemakaian | Font |
| --- | --- |
| Teks umum dan navigasi | Montserrat Alternates |
| Judul dan subjudul | Catamaran |
| Teks bagian layanan | Poppins |

Font normal bobot 400, 500, 600, 700, dan 800 disertakan secara lokal dalam format WOFF2 (subset Latin). Catamaran memakai satu berkas sumber bersama untuk kelima bobot. Berkas diambil melalui [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Montserrat+Alternates:wght@400;500;600;700;800&family=Catamaran:wght@400;500;600;700;800&family=Poppins:wght@400;500;600;700;800&display=swap); berkas font berasal dari fonts.gstatic.com.

Lisensi SIL Open Font License 1.1 disertakan tanpa perubahan:

- [Montserrat Alternates](OFL-montserrat-alternates.txt) — [sumber lisensi](https://github.com/google/fonts/blob/main/ofl/montserratalternates/OFL.txt).
- [Catamaran](OFL-catamaran.txt) — [sumber lisensi](https://github.com/google/fonts/blob/main/ofl/catamaran/OFL.txt).
- [Poppins](OFL-poppins.txt) — [sumber lisensi](https://github.com/google/fonts/blob/main/ofl/poppins/OFL.txt).
